A newspaper front-page infographic summing up the world news of **Tuesday, 17 November 2026** in one image: the Kerch Bridge struck again, drones fired at a US radar in Bahrain, a first Xi–Trump–Putin meeting set for Shenzhen, Peltola flipping the Alaska Senate seat, the US losing its measles-free status, and Nvidia's bumper results.

The image (`entry.png`, 1024×1024) is drawn programmatically with Python + Pillow — flat vector-style icons, real fonts, no photos, no copied artwork. The entry program (`main.py`, Python 3.13 standard library only) copies it byte-for-byte to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`, identical on every run.
